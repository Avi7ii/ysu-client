# 培养方案学分与学位课列调整设计

## 目标

培养方案课程表不再显示课程代码。课程名之后依次显示学分和是否为学位课，使手机端首屏优先呈现用户关心的信息。

## 表格结构

表格列固定为：

1. 课程名
2. 学分
3. 是否学位课
4. 是否必修
5. 学期
6. 课组

“是否学位课”单元格显示紧凑的“是”或“否”标签。现有配色、筛选区、横向滚动行为和其他列的视觉样式保持不变。

## 数据规则

- 学分直接使用培养方案接口的 `XF` 字段。
- 学位课状态只读取教务处培养方案原始响应中的明确学位课标志。
- 禁止根据“必修/选修”、课程名或课组推断学位课状态。
- 原始标志缺失或无法识别时显示“否”，同时解析逻辑保留集中定义，便于后续补充服务器返回值。
- 课程代码不再渲染，但仍保留在数据模型中，避免影响其他内部用途。
- 培养方案页搜索只匹配课程名，用户不可见的课程代码不再作为搜索条件。

## 修改范围

- 教务处培养方案协议模型与解析器：增加布尔型学位课字段。
- 通用培养方案数据模型和 YSU Provider 映射：透传该字段。
- 培养方案表格：删除课程代码列、调整列顺序和空状态跨列数。
- 中英文文案：增加“是否学位课 / Degree Course”和“是 / 否”标签。

## 验证

- 为学位课标志解析补充单元测试，覆盖真、假和缺失值。
- 运行类型检查、单元测试、前端生产构建。
- 构建签名 APK，通过 ADB 保留数据覆盖安装，并验证版本和前台页面可启动。

## 验收标准

- 培养方案表格中看不到课程代码。
- 课程名后的第一列是学分，第二列是是否学位课。
- 学位课状态以“是 / 否”展示，且来源是教务处明确字段。
- 其他页面、课程数据和原有视觉风格不发生变化。
